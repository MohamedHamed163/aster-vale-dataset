## Context and decision record

Lumen Initiative 021 develops Lumen Document Discovery 021 for research teams at Cedar Pilot Organization 021. The workflow helps users find approved source passages. This document covers the architecture decision and gives the team a stable reference for decisions about document discovery. The current review priority is quality; that priority is a stated preference, not a numeric performance claim.

The architecture separates the user interface, domain services, operational storage, and background processing. Typed boundaries prevent a change in a document parser from silently changing account records. Each request carries a correlation identifier so a reviewer can follow the path through the components.

The team considered a single synchronous request path and rejected it for long operations. The selected design records a job before work begins, returns an identifier, and publishes progress. On retry, completed external actions must be reconciled before another action is attempted.

For this project, the team will inspect Lumen 021 Gateway and retain the source records behind each material finding. This record must be read using its recorded publication time. Follow-up decisions should identify their assumptions, the person responsible, and the observable condition that would change the recommendation.
