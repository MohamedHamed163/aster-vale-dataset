## Context and decision record

The architecture separates the user interface, domain services, operational storage, and background processing. Typed boundaries prevent a change in a document parser from silently changing account records. Each request carries a correlation identifier so a reviewer can follow the path through the components.

The team considered a single synchronous request path and rejected it for long operations. The selected design records a job before work begins, returns an identifier, and publishes progress. On retry, completed external actions must be reconciled before another action is attempted.
